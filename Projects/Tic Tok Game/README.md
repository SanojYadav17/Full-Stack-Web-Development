# Tic Tok Game

## About

Tic Tok Game is a beginner-level browser game project built to practise
JavaScript game logic and user interaction. The game page and its behaviour
are kept in separate HTML and JavaScript files.

## Features

- Displays the game interface in the browser
- Uses JavaScript to handle game behaviour
- Gives practice with turns, choices and game conditions
- Keeps the page structure separate from the game logic

## Technologies Used

- HTML5
- JavaScript

## Project Structure

```text
Tic Tok Game/
├── tictokGame.html
├── tictokGame.js
└── README.md
```

- `tictokGame.html` contains the page elements.
- `tictokGame.js` contains the JavaScript used by the game.

## How to Run

1. Open the `Tic Tok Game` folder.
2. Open `tictokGame.html` in a web browser.

No additional setup is needed.

## Learning Outcome

This project is useful for understanding how JavaScript connects with HTML
elements and how simple game rules can be represented with conditions.
