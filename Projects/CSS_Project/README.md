# CSS Project

## About

CSS Project is a music-player style webpage created to practice HTML and CSS.
It contains a sidebar, music sections, album cards, player controls and
image-based interface elements.

The project focuses on building a complete webpage layout from scratch and
organising multiple images and icons inside an assets folder.

## Technologies Used

- HTML5
- CSS3

## Main Areas

- Sidebar navigation
- Main music content area
- Album and playlist cards
- Music player section
- Control icons and artwork
- Responsive spacing and layout

## Project Structure

```text
CSS_Project/
├── index.html
├── style.css
├── assets/
│   ├── album images
│   ├── card images
│   ├── player icons
│   └── navigation icons
└── README.md
```

- `index.html` defines the music-player page.
- `style.css` controls the complete visual layout.
- `assets/` stores the images and icons used by the page.

## How to Run

1. Open the `CSS_Project` folder.
2. Open `index.html` in a browser.

The project uses local files, so no package installation is needed.

## Learning Outcome

This project helps practise CSS layout, card design, image positioning,
reusable spacing and organising assets for a larger webpage.
