# Camera Project

## About

Camera Project is a simple camera-themed webpage made while practicing the
basics of HTML and CSS. The page focuses on presenting a visual hero section,
camera-related content and a clean layout.

This project is useful for learning how to:

- Build a page structure with semantic HTML
- Connect an external CSS file
- Place and style images
- Control spacing, colors and page layout
- Create a simple responsive design

## Technologies Used

- HTML5
- CSS3

## Project Files

```text
Camera_Project/
├── index.html
├── style.css
├── photo.jpg
└── README.md
```

- `index.html` contains the webpage structure and text.
- `style.css` contains the layout, typography, colors and visual styling.
- `photo.jpg` is the image displayed in the webpage.

## How to Run

1. Open the `Camera_Project` folder.
2. Open `index.html` in a browser.

No installation or server is required.

## Learning Outcome

This project is a beginner-friendly example of separating webpage content
(HTML) from presentation (CSS).
