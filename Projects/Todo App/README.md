# Todo App

## About

Todo App is a simple task-management application built with HTML, CSS and
JavaScript. It allows users to add tasks, mark tasks as completed and remove
tasks from the list.

The app also uses browser local storage so tasks can remain available after
the page is refreshed.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks with the browser's local storage
- Use the Enter key to add a task
- Responsive and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## Project Structure

```text
Todo App/
├── README.md
├── todo.html
├── todo.css
└── todo.js
```

- `todo.html` contains the input area, task list and buttons.
- `todo.css` controls the layout and appearance of the application.
- `todo.js` handles task creation, completion, deletion and storage.

## How to Run

1. Open the `Todo App` folder.
2. Open `todo.html` in a web browser.
3. Type a task and add it to the list.

No package installation or backend server is required.

## Learning Outcome

This project helps practise DOM manipulation, event handling, arrays,
functions and saving data with `localStorage`.
